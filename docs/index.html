SEE THE WORKFLOW

From a long stream to short, ready-to-review clips.

Imagine a two-hour creator stream. ClipRally transcribes the speech, proposes timestamped moments, and cuts the selected ranges into vertical MP4s with word-highlight captions. You review the edits before sharing them.

Typical starting point: around 15–55 seconds per clip. Change the minimum and maximum duration in the local app.

Hybrid mode combines commentary with visual activity. Visual-only mode can surface rapid movement and shot changes in silent gameplay too. It still cannot identify semantic events like a GTA kill or locate a named Pushpa scene.

The default path stays small and local. Extra integrations are opt-in and have separate setup requirements.

CORE / 01NO HOSTED API

Everything needed for the first cut.

Choose a video, analyse speech and visual activity, rank candidate moments, render and caption. OpenCV motion analysis runs locally without a hosted AI provider.

  • Local Faster-Whisper transcription
  • Transcript + visual-activity ranking
  • 9:16 FFmpeg rendering
  • Word-highlight subtitles
  • Editable titles and hashtags
  • Export manifest for review

LOCAL BY DEFAULT

Your media stays on the machine doing the work.

In the default workflow, transcription, scoring, reframing, captioning and rendering happen locally. The first Faster-Whisper run downloads a model; once cached, inference can run offline.

✓
No hosted AI account required

Heuristic scoring is the default. Ollama is an optional local model.

✓
No automatic publishing

Review your output. Publishing is a separate, explicit action.

✓
Clear boundaries

Optional URL fetching and publishing have their own network and permission requirements. Choosing OpenAI or Gemini scoring sends candidate transcript text to that provider.

GET STARTED

Run ClipRally on your computer.

The website is the project guide. The video processor runs locally, and its browser interface opens on your own machine. Your footage is not uploaded to this GitHub Pages website.

01

Install the prerequisites

Install Python 3.10+ and FFmpeg. Make sure both ffmpeg and ffprobe work in a terminal.

ffmpeg -version
ffprobe -version
02

Clone and install

Create a virtual environment, then install the local workflow and browser UI.

git clone https://github.com/voyager67/cliprally.git
cd cliprally
python -m venv .venv
# Windows: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -e ".[transcription,visual-analysis,ui]"
03

Open the local interface

Launch the browser interface. It opens on your computer, typically at http://localhost:8501.

cliprally-ui
04

Choose a file and create clips

Choose a source file, set how many clips to create and adjust the duration, then preview and download the MP4s and metadata. The default command-line range is 15–55 seconds; the local UI lets you choose 5–90 seconds.

HONEST BY DESIGN

What ClipRally is — and isn't.

ClipRally is a local-first video editing assistant — not a semantic scene detector, autonomous content farm or promise of viral reach.

  • Hybrid mode combines transcript signals with visual motion and shot-change measurements.
  • Visual-only mode can surface rapid movement and scene changes even when nobody speaks, which can help shortlist action-heavy gameplay.
  • It does not know whether footage shows a GTA kill, race win, stunt or funny moment, and it cannot search a film for a named Pushpa scene or identify an actor.
  • Face-centred cropping is a largest-face heuristic, not active-speaker tracking; automatic gameplay / facecam split-screen is not included.
  • Only process and publish media you own or are authorized to edit and share. A successful clip export does not grant publishing rights.
